# eVision VS11K09A Driver {#vs11k09a-driver}

This driver provides support for ganged-timer PWM driven RGB LED matrices and shared key matrices on keyboards based on the eVision VS11K09A microcontroller (Sonix SN32F248F / SN32F240 architecture), such as the Marvo KG938, SPCGear GK540, and Sharkoon SGK3.

## Hardware Configuration {#hardware-configuration}

The VS11K09A hardware design utilizes 6 independent timers (`CT16B0..2` and `CT32B0..2`) ganged together to drive up to 21 PWM LED columns and read the key matrix during the non-PWM phase.

## Usage {#usage}

In `keyboard.json`:

```json
{
    "matrix_pins": {
        "custom_lite": true,
        "cols": [ "A0", "A1", ... ],
        "rows": [ "D15", "D14", ... ]
    },
    "rgb_matrix": {
        "driver": "vs11k09a"
    }
}
```

In `config.h`:

```c
#pragma once

#define VS11K09A_RGB_MATRIX_ROW_PINS \
    { C0, C1, C3, C4, C14, C15, C5, C6, C7, C8, C9, C10, D0, D1, B6, B7, D2, D3 }
```
